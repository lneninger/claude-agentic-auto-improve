# One-Line Commands For The User

When the user must run something, write a self-contained script file. Then give one short line that runs it.

Never hand over a multi-line block to paste. Never rely on nested quoting, because each shell reads quotes differently and the command breaks.

If a guard blocks you from writing the script, say so plainly. Do not reshape the text to get past the guard.

Say what the line does in one sentence, so the user knows what they are about to run.
